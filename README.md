## About
**ECOMMERCE-LAPTOPP** adalah aplikasi e-commerce untuk penjualan laptop. Aplikasi ini menyediakan katalog produk lengkap dengan fitur pencarian dan filter, keranjang belanja, proses checkout, serta dashboard admin untuk manajemen stok dan pesanan.  
Selain itu, aplikasi ini juga terintegrasi dengan **Midtrans API** untuk pembayaran online dan **RajaOngkir API** untuk perhitungan ongkos kirim secara otomatis.

## 🎯 Tujuan Project
Project ini dibuat sebagai bagian dari skripsi dan portfolio, sekaligus showcase integrasi API (Midtrans untuk pembayaran dan RajaOngkir untuk ongkos kirim).

## ⚙️ Tech Stack
- Laravel (PHP Framework)
- PHP
- MySQL
- Midtrans API (Payment Gateway)
- RajaOngkir API (Shipping Cost)
- JWT Authentication

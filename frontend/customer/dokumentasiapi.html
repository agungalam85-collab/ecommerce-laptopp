Dokumentasi API — Toko Keramik

Dokumentasi lengkap endpoint API. Gunakan header Authorization: Bearer <TOKEN> pada semua endpoint protected (auth:api). Iframe preview hanya untuk endpoint publik/demo tanpa auth.

1. Auth

POST
/api/login — Login (admin/customer)
Request Body JSON: 
{
  "email": "admin@gmail.com",
  "password": "12345678"
}
Response: status, user, token
POST
/api/register — Register umum
Request Body: 
{
  "name": "Nama Lengkap",
  "email": "user@example.com",
  "password": "password",
  "password_confirmation": "password"
}
POST
/api/register-customer — Register customer langsung (returns token)
Request Body: 
{
  "name": "Budi",
  "email": "budi@example.com",
  "password": "12345678"
}
POST
/api/logout — Logout (auth:api)
Use header Authorization: Bearer <token>

3. Admin — Role: admin (auth:api + RoleMiddleware)

Produk

POST
/api/products — Tambah produk (admin)
Body contoh (multipart/form-data jika upload gambar): 
{
  "nama": "Keramik 40x40",
  "slug": "keramik-40x40",
  "harga": 25000,
  "stok": 100,
  "kategori_id": 1,
  "deskripsi": "Keramik motif modern"
}
PUT
/api/products/{id} — Update produk (admin)
{
  "nama": "Keramik 40x40 - Update",
  "harga": 26000
}
DELETE
/api/products/{id} — Hapus produk

Kategori

POST
/api/categories — Tambah kategori

Catatan Penting

  • Gunakan header Authorization: Bearer <token> untuk semua endpoint yang protected.
  • Endpoint webhook (Midtrans) harus terpasang di server publik dan memverifikasi signature Midtrans.
  • Jika ingin saya generate Postman collection / Insomnia export dari dokumentasi ini, saya bisa buatkan.
  • Kalau mau saya ubah jadi Blade (resources/views/api.blade.php) dengan helper URL otomatis, bilang saja.

## 📖 About
**Ecommerce Laptop** adalah aplikasi e-commerce berbasis **Laravel** untuk penjualan laptop.  
Fitur utama:
- Katalog produk dengan pencarian & filter
- Keranjang belanja & proses checkout
- Dashboard admin untuk manajemen stok & pesanan
- Integrasi **Midtrans API** untuk pembayaran online
- Integrasi **RajaOngkir API** untuk ongkos kirim otomatis
- Autentikasi menggunakan **JWT**

## 🎯 Tujuan Project
Project ini dibuat sebagai bagian dari **skripsi & portfolio**, sekaligus showcase integrasi API (Midtrans untuk pembayaran dan RajaOngkir untuk ongkos kirim).

## ⚙️ Tech Stack
- Laravel (PHP Framework)  
- PHP 8.2  
- MySQL  
- Midtrans API (Payment Gateway)  
- RajaOngkir API (Shipping Cost)  
- JWT Authentication  

## 🚀 Features
- 🔍 Search & Filter produk  
- 🛒 Shopping Cart  
- 💳 Payment Gateway (Midtrans)  
- 🚚 Shipping Cost (RajaOngkir)  
- 📊 Admin Dashboard
